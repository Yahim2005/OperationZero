# OperationZero
Operation Zero is a bomb-defusal game. A LilyPad Arduino bomb (keypad, joystick, RFID, ultrasonic sensor, accelerometer, buzzer) talks over ZigBee to a Java Swing game with a Pac-Man style screen. Players beat 6 mini-games in 3 minutes without shaking the bomb. Strikes add 5 s; faster, cleaner runs score higher.
